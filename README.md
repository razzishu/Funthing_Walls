# FunThingWalls Studio 🎨

![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg?style=for-the-badge)

**FunThingWalls** is a next-generation Android Customization Studio. It goes beyond static wallpapers by transforming your home and lock screens into living, hardware-accelerated ecosystems. 

Whether you want mathematically accurate sunsets, a dynamic audio-visualizer, or a procedural weather engine that reacts to the real world, FunThingWalls has it built-in.

---

## ✨ Key Features

* 🌦️ **Procedural Weather Engine:** A custom, hardware-accelerated 60FPS physics engine that renders live weather (Rain, Blizzard, Hail, Thunderstorms, Fireflies, and Flocks of Birds) using real-world weather data. Includes 3D Gyroscope Parallax.
* 🤖 **Smart Auto-Changer:** Seamlessly cycles your background from the Explore feed on a custom timer. It automatically pauses when a local gallery image is applied to prevent engine conflicts.
* 🎵 **Chameleon Audio Glass:** Real-time screen-reading audio visualization that seamlessly reacts to your system's music and media.
* 🌅 **Cinematic Time Sync:** Mathematical color grading that dynamically matches the sun and moon arcs in your exact timezone, applying a warm cinematic grade at sunset and dimming at night.
* 🎛️ **Advanced Matrix Editor:** Independent zoom, pan, blur, dim, and grayscale controls for Lock and Home screens.
* 🔋 **Deep Battery Optimization:** Heavily optimized object pooling and strict Doze-mode constraints ensure these Live Wallpapers consume practically 0% battery while the screen is off.
* 🔒 **Secure Scoped Storage:** Download and manage 4K assets directly in a dedicated 'My Studio' gallery without invasive device storage permissions.

## 🚀 Installation

You can download the latest stable release directly from the Releases page.
1. Go to the [Releases Tab](../../releases).
2. Download the `app-release.apk` file from the latest version.
3. Install the APK on your Android device (Android 12 / API 31+ required).

---

## 🔑 API Keys Configuration

FunThingWalls fetches breathtaking community imagery from Pexels and Wallhaven. While the app will run without them, you need API keys to unlock the Explore feed's full potential.

1. Open the app and navigate to **Settings**.
2. **Pexels (Required):** Get a free API key from [Pexels API](https://www.pexels.com/api/).
3. **Wallhaven (Optional):** Get your API key from your [Wallhaven Account Settings](https://wallhaven.cc/settings/account).
4. Paste the keys into the app and hit **Save & Validate**.
